### What it does
Standardizes 20 API routes by replacing the older `getSession()` pattern with the modern `requireAuth(request)` pattern. Enables consistent auth improvements and future middleware evolution.

- `/api/market-intel/sources/[id]/route.js`

**Other (4):**
- `/api/link-preview/route.js`
- `/api/alerts/route.js`
- `/api/market-intel/poll/route.js`
- `/api/projects/[id]/estimate/route.js`
- `/api/auth/me/route.js` (special case: uses `jwtUser` alias to avoid collision)

### Pattern change

```js
// OLD
import { getSession } from '@/lib/auth';
export async function GET() {
  const session = await getSession();
  if (!session) return error;
}

// NEW
import { requireAuth } from '@/lib/auth';
export async function GET(request) {
  const { user, error } = await requireAuth(request);
  if (error) return error;
}
```

### Special case: auth/me

To avoid collision with re-fetched user variable:
```js
const { user: jwtUser, error } = await requireAuth(request);
```
